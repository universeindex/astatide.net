barracuda engine

Barracuda Engine is an experimental 3D game engine. It is designed to be simple for beginners, but limitless and empowering for experienced developers.

Currently it is in an extremely early stage of development and is nowhere close to being usable for real projects. It is not yet publically available, but will eventually be released most likely using the Zlib license. Check back later!
